# Spørsmål nr. 165 fra SP til STB 2021

- **Parti:** SP
- **Spørsmålsnr:** 165
- **Dato på spørsmålet:** 08.10.2020
- **Departement:** Kunnskapsdepartementet
- **Tittel:** Svar på spørsmål 165 fra Finanskomiteen/SPs fraksjon av 8.10.2020

## Utvikling i antall stillinger i KD siden 2010

200 Hvordan har utviklingen i antall stillinger i Kunnskapsdepartementet vært siden 2010 og fram til og med budsjettforslaget for 2020?

## Svar

Spørsmålet er forelagt Kunnskapsdepartementet, som har gitt følgende svar:

«Under følger en oversikt over utviklingen i antall stillinger i Kunnskapsdepartementet i perioden 2010–20.

|  | Antall stillinger |
|---|---|
| 2010 | 330 |
| 2011 | 332 |
| 2012 | 313 |
| 2013 | 296 |
| 2014 | 313 |
| 2015 | 306 |
| 2016 | 305 |
| 2017 | 297 |
| 2018 | 326 |
| 2019 | 327 |
| 2020 | 327 |

Økningen fra 2017 til 2018 skyldes at integreringsavdelingen ble overført fra Justis- og beredskapsdepartementet til Kunnskapsdepartementet.

Totalt antall ansatte for årene 2010-2014 finner vi i statens tjenestemannsregister (pr 1. okt) Etter 2014 finnes ikke tall i denne databasen, men er hentet fra Prop 1 S (pr 31. desember)

For 2020 er det 327 ansatte pr. dags dato.»
