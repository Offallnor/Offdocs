# Spørsmål nr. 111 fra AP til RNB 2021

- **Parti:** AP
- **Spørsmålsnr:** 111
- **Dato på spørsmålet:** 18.05.2021
- **Departement:** Kunnskapsdepartementet
- **Tittel:** Svar på spørsmål 111 fra Finanskomiteen/APs fraksjon av 18.5.2021

## Yrkesfaglig opplæring i skole

Hva er gjennomsnittlig kostnad for ett år yrkesfaglig opplæring i skole? Vi ber om at svaret oppgis for hvert utdanningprogram og i snitt for alle de yrkesfaglige utdanningprogrammene.

## Svar

Spørsmålet er forelagt Kunnskapsdepartementet, som har gitt følgende svar:

«Tabellen under viser direkte utgifter per elev i videregående opplæring for yrkesfaglige utdanningsprogram. Dette er KOSTRA-tall for 2019, da foreløpige KOSTRA-tall for 2020 ikke omfatter et helt år for de yrkesfaglige utdanningsprogrammene som var nye i 2020.

| Utdanningsprogram | Kostnad (kroner) |

| Elektro og datateknologi | 104 828 |
| Design og håndverk | 110 207 |
| Restaurant- og matfag | 129 148 |
| Helse- og oppvekstfag | 90 371 |
| Teknologi- og industrifag | 111 393 |
| Naturbruk | 165 435 |
| Service og samferdsel | 106 023 |
| Yrkesfaglige utdanningsprogrammer samlet | 107 067 |
