# Spørsmål nr. 405 fra H til STB 2024

- **Parti:** H
- **Spørsmålsnr:** 405
- **Dato på spørsmålet:** 17.10.2023
- **Departement:** Kunnskapsdepartementet
- **Tittel:** Svar på spørsmål 405 fra Finanskomiteen/Hs fraksjon av 17.10.2023

## Forsøkskommuneprosjektet

Ber om en oversikt over søknader og eventuelt godkjente prosjekter som gjelder barnehage og skoler i forsøkskommuneprosjektet.

## Svar

Spørsmålet er forelagt Kunnskapsdepartementet, som har gitt følgende svar:

«Prosjektet innebærer at kommunene og fylkeskommunene kan søke på forsøk innen alle sektorer eller på tvers av sektorer. Forsøkene må være innenfor rammene av eksisterende forsøkshjemler. Forsøk som vurderes etter forsøksloven kan for eksempel ikke innskrenke individuelle rettigheter eller saksbehandlingsregler som ivaretar enkeltpersoners rettssikkerhet.

Søknadsfristen for foreløpige søknader var 18. september 2023. De involverte departementene er nå i ferd med å gå gjennom de foreløpige søknadene, og det er ikke tatt stilling til noen prosjekter eller gitt noen godkjenninger.

Forsøksordningen vil være avgrenset når det gjelder hvor mange kommuner og fylkeskommuner som får innvilget forsøk. Målet er bl.a. å få til gode forsøk som kan grupperes tematisk og følges opp i nettverk. KDD vil i samarbeid med berørte departementer foreta en prioritering basert på innkomne søknader.

Nedenfor følger en oversikt over foreløpige søknader på KDs områder, dvs. grunnopplæring og barnehage. I tillegg til disse kan det være foreløpige søknader som vurderes av andre departementer, men som også berører KDs områder.

| Kommune | Tema |
|---|---|
| Elverum | Samhandling velferdstjenester. Barnehage som tverrfaglig samarbeid til flyktningfamilier |
| Frogn | Barnehage, pedagognorm |
| Indre Østfold | Individuelt tilrettelagt barnehagetilbud for barn med nedsatt funksjonsevne |
| Indre Østfold | Skole. Vurderingsformer |
| Krødsherad, Modum, Sigdal | Spesialpedagogiske tiltak, skole og barnehage |
| Lindesnes | Bruke arbeidslivet som en del av skolens opplæringsarena |
| Nesodden | Barnehageopptak |
| Nordre Follo | Barnehage, arealbruk |
| Nordre Follo | Barnehage. Dispensasjon utdanningskrav |
| Nordre Follo | Læringsløp for elever med stort skolefravær |
| Oslo | Overgang mellom ungdomsskole og videregående opplæring |
| Rana | Løpende barnehageopptak |
| Råde | Fag- og timefordeling. Undervisning med fokus på elevaktivitet og elevmedvirkning |
| Strand | Målform, organisering skole |
| Øygarden | Spesialpedagogiske tiltak skole. |

»
