# Spørsmål nr. 23 fra SV til STB 2024

- **Parti:** SV
- **Spørsmålsnr:** 23
- **Dato på spørsmålet:** 06.10.2023
- **Departement:** Kunnskapsdepartementet
- **Tittel:** Svar på spørsmål 23 fra Finanskomiteen/SVs fraksjon av 6.10.2023

## Gratis halvdagsplass i SFO for 3. og 4. trinn

Hva er provenyeffekten av i) å innføre gratis halvdagsplass på SFO for henholdsvis 3. og 4. trinn? ii) innføre gratis heldagsplass på SFO for henholdsvis 1., 2., 3. og 4. trinn? iii) én time gratis SFO i hhv. 1., 2., 3 og 4. trinn? Ber om at det i svarene tas utgangspunkt i i) dagens deltakelse i SFO, ii) dagens deltakelse i SFO for 1. 2. trinn og iii) full deltakelse Ber om både halv- og helårseffekt.
