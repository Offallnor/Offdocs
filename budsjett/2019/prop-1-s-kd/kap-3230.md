# Kap. 3230 Statleg spesialpedagogisk støttesystem

|  |  |  | (i 1 000 kr) |  |
|---|---|---|---|---|
| Post | Nemning | Rekneskap 2017 | Saldert budsjett 2018 | Forslag 2019 |
| 01 | Inntekter frå oppdrag | 35 902 | 46 344 | 47 449 |
| 02 | Salsinntekter o.a. | 10 917 | 10 248 | 10 493 |
|  | Sum kap. 3230 | 46 819 | 56 592 | 57 942 |

Post 01 gjeld oppdragsverksemd som Statped utfører for kommunar, fylkeskommunar, høgskolar, universitet m.m. Post 02 gjeld sal av læremiddel, sal av elevprodukt, sal frå kantine, utleige av lokale, inntekter frå hjelpemiddeltilpassing og inntekter frå kurs. Departementet foreslår å føre inntektsløyvingane vidare på same nivå som i 2018.
