# Kap. 3225 Tiltak i grunnopplæringa

|  |  |  | (i 1 000 kr) |  |
|---|---|---|---|---|
| Post | Nemning | Rekneskap 2017 | Saldert budsjett 2018 | Forslag 2019 |
| 04 | Refusjon av ODA-godkjende utgifter | 77 594 | 55 119 | 19 734 |
|  | Sum kap. 3225 | 77 594 | 55 119 | 19 734 |

Visse innanlandske utgifter til flyktningar kan i høve til statistikkdirektiva til OECD bli definerte som offentleg utviklingshjelp. Ein del av løyvinga på kap. 225 post 64 blir rapportert som utviklingshjelp. Kunnskapsdepartementet foreslår ei tilsvarande løyving på kap. 3225 post 04. Refusjon av ODA-godkjente utgifter er rekna til 19,7 mill. kroner i 2019.
