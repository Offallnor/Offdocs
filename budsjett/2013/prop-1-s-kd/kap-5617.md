# Kap. 5617 Renter frå Statens lånekasse for utdanning

|  |  |  |  | (i 1 000 kr) |
|---|---|---|---|---|
| Post | Nemning | Rekneskap 2011 | Saldert budsjett 2012 | Forslag 2013 |
| 80 | Renter | 3 866 019 | 4 824 471 | 3 377 934 |
|  | Sum kap. 5617 | 3 866 019 | 4 824 471 | 3 377 934 |

Løyvinga på posten gjeld renter til staten for alle utlån til Lånekassens kundar. Dette gjeld renter som er belasta kundar i tilbakebetalingsfasen, og renter som er løyvde på tilskottspostar til å dekkje kostnadene til staten på lån som er rentefrie under utdanninga, og på lån som er avskrivne.

Rentestøtta er berekna til å utgjere om lag 966 mill. kroner, medan opptente og innbetalte renter frå kundane er berekna til å utgjere om lag 1,4 mrd. kroner i 2013. Opptente ikkje-betalte renter frå kundane er berekna til å utgjere om lag 968 mill. kroner, medan årets renter frå tap/kostnadsløyvingar er berekna til å utgjere om lag 47 mill. kroner i 2013.
