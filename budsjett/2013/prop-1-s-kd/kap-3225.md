# Kap. 3225 Tiltak i grunnopplæringa

|  |  |  |  | (i 1 000 kr) |
|---|---|---|---|---|
| Post | Nemning | Rekneskap 2011 | Saldert budsjett 2012 | Forslag 2013 |
| 04 | Refusjon av ODA-godkjende utgifter | 57 352 | 50 423 | 42 858 |
|  | Sum kap. 3225 | 57 352 | 50 423 | 42 858 |

Visse innanlandske utgifter til flyktningar kan i høve til statistikkdirektiva til OECD bli definerte som offentleg utviklingshjelp. Ein del av løyvinga på kap. 225 post 64 blir rapportert som utviklingshjelp. Kunnskapsdepartementet foreslår ei tilsvarande løyving over kap. 3225 post 04. Refusjon av ODA-godkjende utgifter er i 2013 på om lag 42,9 mill. kroner.
