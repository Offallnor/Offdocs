# Kap. 3230 Statleg spesialpedagogisk støttesystem

|  |  |  |  | (i 1 000 kr) |
|---|---|---|---|---|
| Post | Nemning | Rekneskap 2011 | Saldert budsjett 2012 | Forslag 2013 |
| 01 | Inntekter frå oppdrag | 64 267 | 54 632 | 56 435 |
| 02 | Salsinntekter o.a. | 18 285 | 13 694 | 14 146 |
|  | Sum kap. 3230 | 82 552 | 68 326 | 70 581 |

Post 01 gjeld oppdragsverksemd som Statped utfører for kommunar, fylkeskommunar, høgskolar, universitet m.m.

Post 02 gjeld sal av læremiddel, sal av elevprodukt, sal frå kantine, utleige av lokale, inntekter frå hjelpemiddeltilpassing og inntekter frå kurs.

Departementet foreslår å føre løyvingane på postane vidare på same nivå som i 2012.
