# Kap. 3242 Noregs grøne fagskule – Vea

| KPVA |  |  |  | (i 1 000 kroner) |
|---|---|---|---|---|
| Post | Nemning | Rekneskap 2025 | Saldert budsjett 2026 | Forslag 2027 |
| 02 | Salsinntekter o.a. | 10 677 | 8 104 | 8 404 |
| 61 | Refusjon frå fylkeskommunar |  | 54 |  |
|  | Sum | 10 677 | 8 158 | 8 404 |

Post 02 gjeld inntekter frå mellom anna prosjektstøtte, semesteravgift, sal i kantine, hybelutleige og kortare kurs. Departementet foreslår å løyve 8,4 mill. kroner på post 02.

Post 61 gjeld betaling frå fylkeskommunar for kjøp av opplæringsplassar ved Noregs grøne fagskule – Vea. Post 61 er knytt til eit tilbod i vidaregåande opplæring som Vea ikkje lenger tilbyr. På grunn av bortfallet av tilbodet foreslår departementet å avvikle posten.
