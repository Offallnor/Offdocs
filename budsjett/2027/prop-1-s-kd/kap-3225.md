# Kap. 3225 Tiltak i grunnopplæringa

|  |  |  | (i 1 000 kroner) |  |
|---|---|---|---|---|
| Post | Nemning | Rekneskap 2025 | Saldert budsjett 2026 | Forslag 2027 |
| 04 | Refusjon av ODA-godkjende utgifter | 163 475 | 176 687 | 153 145 |
|  | Sum kap. 3225 | 163 475 | 176 687 | 153 145 |

Visse innanlandske utgifter til flyktningar kan etter statistikkdirektiva frå OECD definerast som offentleg utviklingshjelp. Ein del av løyvinga på kap. 225, post 64 blir rapportert som utviklingshjelp, og refusjon frå Utanriksdepartementet blir ført på kap. 3225, post 04. Refusjon av ODA-godkjende utgifter er rekna til 153,1 mill. kroner i 2027.
