# Kap. 3225 Tiltak i grunnopplæringa

|  |  |  |  | (i 1 000 kr) |
|---|---|---|---|---|
| Post | Nemning | Rekneskap 2023 | Saldert budsjett 2024 | Forslag 2025 |
| 04 | Refusjon av ODA-godkjende utgifter | 198 749 | 302 337 | 293 709 |
|  | Sum kap. 3225 | 198 749 | 302 337 | 293 709 |

Visse innanlandske utgifter til flyktningar kan etter statistikkdirektiva til OECD definerast som offentleg utviklingshjelp. Ein del av løyvinga på kap. 225, post 64 blir rapportert som utviklingshjelp, og refusjon frå Utanriksdepartementet blir ført på kap. 3225, post 04. Refusjon av ODA-godkjende utgifter er rekna til 293,7 mill. kroner i 2025.
