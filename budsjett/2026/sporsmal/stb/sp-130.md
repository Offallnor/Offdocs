# Spørsmål nr. 130 fra SP til STB 2026

- **Parti:** SP
- **Spørsmålsnr:** 130
- **Dato på spørsmålet:** 16.10.2025
- **Departement:** Kunnskapsdepartementet
- **Tittel:** Svar på spørsmål 130 fra Finanskomiteen/SPs fraksjon av 16.10.2025

## Offentlige videregående skoler

Hvor mange offentlige videregående skoler er det i Norge nå, og hvordan fordeler disse seg per fylke?

## Svar

Spørsmålet er forelagt Kunnskapsdepartementet, som har gitt følgende svar:

«I skoleåret 2024-25 var det 316 offentlige videregående skoler i Norge. Tabellen under viser hvordan disse skolene er fordelt per fylke. Tallene er hentet fra analysebrettet for videregående skoler fra Udir.

| Fylke | Antall offentlige videregående skoler |
|---|---|
| Agder | 18 |
| Akershus | 35 |
| Buskerud | 13 |
| Finnmark | 10 |
| Innlandet | 25 |
| Møre og Romsdal | 20 |
| Nordland | 17 |
| Oslo | 32 |
| Rogaland | 25 |
| Telemark | 11 |
| Troms | 14 |
| Trøndelag | 33 |
| Vestfold | 10 |
| Vestland | 42 |
| Østfold | 11 |

»
