# Referansekatalogen for IT-standardar Bruk av språkkodar på offentlege nettsider

Det blir tilrådd å leggje ISO 639 til grunn for deklarering av språkkodar for offentlege nettsider i HTML.

Laga: 19. juni 2020

Sist endra: 13. desember 2022

For dei språka som har språkkodar i ISO 639-1 (tobokstavskodar) bør denne brukast. Om ikkje må ein sjå vidare til ISO 639-2 og ISO 639-3 (trebokstavskodar). Eintydige kodar bør brukast framfor språkgruppekodar. Av dette følgjer at det må skiljast mellom ulike samiske språk, og mellom bokmål og nynorsk.

Det blir presisert at tilrådinga gjeld alle språk. Med bakgrunn i prinsippa over, framhevar vi likevel desse språkkodane, som vil vere rett å bruke for dei lovbestemte språka for offentleg sektor i Noreg:

- Bokmål: nb (ISO 639, Set 1)
- Nynorsk: nn (ISO 639, Set 1)
- Nordsamisk: se (ISO 639, Set 1)
- Lulesamisk: smj (ISO 639, Set 2)
- Sørsamisk: sma (ISO 639, Set 2)
- Finsk: fi (ISO 639, Set 1)
- Kvensk: fkv (ISO 639, Set 3)
- Andre språk: Følg prinsippa over.
