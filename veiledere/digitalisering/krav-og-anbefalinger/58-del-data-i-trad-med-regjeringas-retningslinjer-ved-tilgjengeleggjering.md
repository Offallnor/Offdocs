# Del data i tråd med regjeringas retningslinjer ved tilgjengeleggjering av offentlege data

Retningslinjene hjelper verksemda med å gjere data tilgjengeleg slik at det er mogleg for andre å realisere verdien av data. Retningslinjene legg til rette for å kunne beskrive korleis dataa kan brukast og korleis dei teknisk er gjort tilgjengeleg.
