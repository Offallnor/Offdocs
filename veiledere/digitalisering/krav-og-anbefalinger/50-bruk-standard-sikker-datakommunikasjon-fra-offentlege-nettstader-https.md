# Krav og anbefalingar innan digitalisering Bruk standard for sikker datakommunikasjon frå offentlege nettstader (HTTPS)

HTTPS er overføring av nettrafikk over ei sikker forbindelse. Ved å nytte krypteringsprotokollen Transport Layer Security (TLS) kan klienten verifisere identiteten til tjenestelevendøren. Deretter overførast netttrafikken kryptert, og gjer den uleseleg for uvedkommande.
